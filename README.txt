AI4E — Animated Modern Government Design 4

Complete responsive website with the supplied AI4E logo and event photographs.

Files
- index.html — website content and layout
- styles.css — base styles
- design-4.css — new visual design, responsive layouts, and animation effects
- app.js — navigation, learning details, resource guides, gallery and slideshow
- motion.js — animation control, scroll reveals, reading progress, back-to-top
- assets/ — logo and event photographs

Preview
Extract the ZIP and open index.html in a modern browser.

Deploy, including to InfinityFree
Upload index.html, styles.css, design-4.css, app.js, motion.js and the complete
assets folder to your public website root (htdocs on InfinityFree).
Keep all filenames and folder structure. No database, PHP, or build step is required.

Animation effects
Staggered hero entrance; floating AI4E emblem and orbit; soft background motion;
scroll reveals; interactive cards; hover effects; reading progress indicator.
Use Pause animations / Play animations above the masthead to control effects.
The site respects device reduced-motion preferences. The photo slideshow has
its own play/pause control in the photo viewer.

Editing
Edit the page text in index.html, visual styling in design-4.css, and gallery
captions and resource-guide contents in app.js. Replace images in assets using
the same filenames or update their references in the code.

This is a static website. It has no admin panel, database, account system, or
inquiry form backend. Email inquiry links open the visitor's email application.
